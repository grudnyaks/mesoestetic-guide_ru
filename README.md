# mesoestetic — справочник препаратов (Android, iOS, веб)

## Файлы

- `index.html` — сам справочник (работает и в браузере)
- `version.json` — номер версии справочника и текст «что нового» для обновления по воздуху
- `package.json`, `capacitor.config.json` — настройки сборки приложений
- `android-res.zip` — иконка Android (не распаковывать!), `android-theme.py` — тема и настройки Android
- `ios-setup.py` — иконка, экран запуска и версия iOS
- `icons/`, `manifest.webmanifest`, `sw.js` — иконки и офлайн-режим веб-версии
- `tools/` — выгрузка данных в таблицу и синхронизация с Google-таблицей
- `bump-version.py` — поднимает номер версии сразу во всех местах

## Android

После каждого изменения в `main` сборка запускается сама (5–8 минут).
**Actions** → «Сборка APK» → последняя с зелёной галочкой → внизу **Artifacts** → `mesoestetic-guide-apk`.

## iOS

Сценарий «Сборка iOS» собирает приложение на macOS-сервере GitHub. Варианты установки:

1. **Веб-версия, без App Store (работает сразу).** Включите один раз: Settings → Pages → Source: **GitHub Actions**.
   Справочник будет по адресу `https://grudnyaks.github.io/mesoestetic-guide_ru/`. На iPhone откройте его в Safari →
   «Поделиться» → «На экран Домой». Справочник откроется как приложение и будет работать офлайн.
2. **Неподписанный .ipa** (артефакт `mesoestetic-ios-unsigned`) — для установки на свой iPhone через Sideloadly или AltStore
   с личным Apple ID. Бесплатный Apple ID — переподписывать раз в 7 дней.
3. **TestFlight и App Store** — нужен Apple Developer Program (99 $ в год). Добавьте в Settings → Secrets and variables → Actions → **Secrets**:
   - `IOS_CERT_P12` — сертификат Apple Distribution в .p12, в base64 (`base64 -i cert.p12`); `IOS_CERT_PASSWORD` — его пароль;
   - `IOS_PROFILE` — профиль App Store для `ru.mesoestetic.guide`, в base64;
   - `APPSTORE_API_KEY_ID`, `APPSTORE_ISSUER_ID`, `APPSTORE_API_KEY` — ключ App Store Connect API (содержимое .p8).
   После этого каждая сборка сама уходит в TestFlight.

## Обновление по воздуху

Установленное приложение (Android и iOS) при запуске смотрит `version.json` в этом репозитории. Если версия новее, скачивает свежий
`index.html` и предлагает «Перезапустить». Проверить вручную: **О компании → Настройки → Проверить обновления**.
Переустанавливать приложение нужно только при изменениях нативной части (иконка, плагины, `package.json`, `*.py`).

Выпуск обновления вручную: правки в `index.html` → `python3 bump-version.py "что нового"` → коммит в `main`.
Если новая версия не запустится, приложение само вернётся к встроенной.

> Обновления скачиваются с `raw.githubusercontent.com` — поэтому репозиторий должен оставаться **публичным**
> (или нужно перенести `version.json` и `index.html` на другой публичный адрес — константа `OTA_BASE` в `index.html`).

## Правка текстов через Google-таблицу

1. Скачайте шаблон `mesoestetic-guide-data.xlsx` (его можно пересоздать: `python3 tools/sheet_export.py`) и импортируйте в Google Таблицы
   (Файл → Импортировать → Загрузить → «Заменить таблицу»).
2. Файл → Поделиться → **Опубликовать в интернете** → выберите лист «Препараты» → формат **CSV** → Опубликовать. Скопируйте ссылку.
   Повторите для листов «Линии» и «Глоссарий».
3. В GitHub: Settings → Secrets and variables → Actions → **Variables** → добавьте
   `SHEET_PRODUCTS_CSV`, `SHEET_LINES_CSV`, `SHEET_GLOSSARY_CSV` со ссылками.
4. Всё. Раз в 6 часов (или сразу: Actions → «Синхронизация с Google-таблицей» → Run workflow) изменения применяются,
   версия поднимается, приложения получают обновление по воздуху, собирается новый APK.

Удалить препарат — «да» в колонке «Удалить» (или удалить строку). Добавить — новая строка. Ошибки в таблице
(нет колонки, повтор артикула, несуществующая линия, пропало больше половины строк) останавливают синхронизацию — причина видна в Actions.

## Если сборка красная

Откройте её → слева задание → разверните шаг с красным крестиком и пришлите скриншот последних строк.
