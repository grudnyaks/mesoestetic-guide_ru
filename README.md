# mesoestetic — справочник препаратов (Android)

## Файлы

- `index.html` — сам справочник (работает и в браузере)
- `version.json` — номер текущей версии справочника и текст «что нового» для обновления по воздуху
- `package.json`, `capacitor.config.json` — настройки сборки
- `android-res.zip` — иконка приложения (не распаковывать!)
- `android-theme.py` — тема Android (светлая/тёмная как в системе), чёрный старт под анимированную заставку, номер версии APK
- `bump-version.py` — поднимает номер версии сразу во всех местах
- `build-apk.yml` — копия сценария сборки (рабочий лежит в `.github/workflows/`)
- `README.md` — эта инструкция

## Как получить APK

После каждого изменения в ветке `main` сборка запускается сама (5–8 минут).
Вкладка **Actions** → последняя сборка с зелёной галочкой → внизу **Artifacts** → `mesoestetic-guide-apk`.
Внутри — `mesoestetic-guide.apk`. Перешлите его на телефон, откройте и разрешите установку из неизвестных источников.

## Обновление по воздуху

Установленное приложение при запуске (если есть интернет) смотрит `version.json` в этом репозитории.
Если там версия новее, оно скачивает свежий `index.html`, сохраняет его в памяти телефона и предлагает
«Перезапустить». Со следующего запуска справочник открывается уже в новой версии, даже без интернета.
Проверить вручную: **О компании → Настройки → Проверить обновления**.

Переустанавливать APK нужно только при изменениях нативной части (иконка, плагины, `android-theme.py`, `package.json`).
Тексты, препараты, глоссарий, оформление и логика — всё приходит по воздуху.

Как выпустить обновление:

1. Внесите правки в `index.html`.
2. Поднимите версию: `python3 bump-version.py "Коротко, что нового"`. Номер должен совпадать в
   `version.json` и в двух местах `index.html` — сборка проверяет это и не пропустит расхождение.
3. Закоммитьте `index.html` и `version.json` в `main`.

Защита от сбоев: если новая версия не смогла запуститься, при следующем старте приложение
откатится на встроенную и больше не будет ставить эту версию.

> Приложение скачивает файлы по адресу `raw.githubusercontent.com/grudnyaks/mesoestetic-guide_ru/main/`.
> Он открывается без входа, только если репозиторий **публичный**. Адрес задан в `index.html`, константа `OTA_BASE`.

## Если сборка красная

Откройте её → слева **build** → разверните шаг с красным крестиком и пришлите скриншот последних строк.
